# Welcome to _MBGA_ (Make BASIC Great Again) 🏗️🧱♻️
🔌 This repository of projects is dedicated to **WinRT** (Windows Runtime) and using it to breathe new life into classic **VB6/VBA** applications as well as their 64-bit successor **twinBASIC**. Welcome to a corner of GitHub where “legacy” doesn't mean “left behind” but is just another word for “still getting the job done.”

🧩 The focus here is on modernization with respect to preserving what works, upgrading what matters and quietly replacing “that one form nobody wants to touch” with something far more civilized. The approach? Bridging the past and present using modern Windows technologies—WinRT Classes, XAML Islands and thoughtfully crafted **COM Type Libraries** that translate **WinRT** interfaces and types into something these venerable BASIC dialects can understand without complaint. The result is seamless integration of _contemporary UI_, _async APIs_ and _Windows features_ into both 32-bit and 64-bit environments, without abandoning the ecosystems that you've been relying on for decades or throwing away years of battle‑tested logic.

🚀 Think of it as teaching old code new tricks—without making it feel obsolete. If you're interested in extending the life of your applications, modernizing user interfaces or exploring how far **VB6/VBA/twinBASIC** can really go when paired with **WinRT**, you're in the right place.
